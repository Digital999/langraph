# 实名认证常见问题

## 什么是实名认证？

实名认证是根据国家相关法律法规要求，用户需要使用真实身份信息进行手机号码注册和使用。

## 如何办理实名认证？

### 线上办理
1. 登录官方APP或网站
2. 进入"个人中心" → "实名认证"
3. 上传身份证正反面照片
4. 进行人脸识别验证
5. 等待审核（通常1-3个工作日）

### 线下办理
1. 携带本人身份证原件
2. 前往就近营业厅
3. 工作人员协助办理
4. 现场完成认证

## 实名认证需要哪些材料？

- 中国大陆居民：二代身份证
- 港澳台居民：港澳居民来往内地通行证、台湾居民来往大陆通行证
- 外籍人士：护照

## 未实名认证会有什么影响？

- 无法办理新号码
- 现有号码可能被停机
- 无法办理套餐变更等业务
- 影响正常使用

## 实名认证信息可以修改吗？

实名认证信息一旦提交审核通过，无法自行修改。如需修改，请携带有效证件前往营业厅办理。

## 实名认证安全吗？

我们采用银行级加密技术保护您的个人信息，严格遵守国家信息安全法规，不会泄露您的隐私。
